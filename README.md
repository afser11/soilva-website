# Soilva Website Starter

This is a responsive static website prototype for soilva.in.

## Before publishing

1. Replace every `91XXXXXXXXXX` with your actual WhatsApp number in international format.
2. Replace `YOUR_EMAIL_ADDRESS` in the contact form action.
3. Confirm all product claims before publishing.
4. Add your actual business address, contact information, policies and FSSAI details after approval.
5. Replace concept images with final approved product photographs/artwork before commercial launch.

## Preview locally

Double-click `index.html`, or run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Recommended hosting

Upload this folder to a GitHub repository and import it into Vercel, or deploy it through Vercel CLI. Add `soilva.in` in Vercel Project Settings > Domains, then copy the exact DNS records shown by Vercel into the DNS section of your GoDaddy domain.
